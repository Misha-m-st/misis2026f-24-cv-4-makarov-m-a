# document-vos

**Сегментация документа во всём видео по маске первого кадра.**

[О проекте](#о-проекте) · [Быстрый старт](#быстрый-старт) · [Свои видео](#свои-видео) · [Результаты](#модели-и-результаты) · [Воспроизведение](#обучение-и-воспроизведение) · [Документация](#документация)

`document-vos` — проект по адаптации [Cutie](https://github.com/hkchengrex/Cutie)
к видео документов. Он объединяет дообученную модель, подготовку данных,
инференс и парное сравнение с исходной Cutie в одном воспроизводимом процессе.
На вход подаются кадры и первая маска документа; на выходе получаются
бинарные PNG-маски и видео с наложением.

![Слева — исходные кадры SmartDoc2015, справа — сохранённые маски модели finetuned](docs/assets/document-tracking.gif)

*Реальный результат `finetuned` на последовательности `background01/patent001`
из [SmartDoc2015](https://github.com/jchazalon/smartdoc15-ch1-dataset)
(Burie et al., ICDAR 2015; [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).
Для демонстрации кадры уменьшены и прорежены, добавлены подписи и наложение.
Исходные timestamps неизвестны; скорость анимации задана для визуализации.
Пример принадлежит валидационной выборке.*

## О проекте

При съёмке с телефона документ меняет положение, масштаб и перспективу;
часть страницы может перекрываться другими предметами. Задача проекта —
выделять область одного документа на последовательных кадрах, используя
начальную маску как указание на нужный объект. Такой режим называется
video object segmentation, или VOS.

Cutie распространяет маску по видео с помощью временной памяти. В этом проекте
её архитектура используется для задачи документов: подготовлены адаптеры
шести датасетов, выполнено дообучение и зафиксирован протокол сравнения.
Полученные маски можно использовать при дальнейшей обработке видеокадров,
подготовке данных и исследовании качества выделения страницы.

В центре проекта две задачи: сделать обработку собственного видео доступной
через несколько команд и сохранить возможность проверить происхождение
данных, весов и результатов эксперимента.

## Возможности

- **Маска на каждом кадре.** Инициализация бинарной PNG или четырьмя углами;
  сохранение масок в исходном разрешении и MP4 с наложением.
- **Две модели.** `finetuned` для обработки документов по умолчанию и `baseline`
  для сравнения с исходной Cutie.
- **Подготовка и обучение.** Общий процесс для SmartDoc2015, MIDV-2020,
  MIDV-500, MIDV-2019, MIDV-Holo и DLC-2021.
- **Воспроизводимые эксперименты.** Фиксированные выборки, seed, контрольные
  суммы, resolved-конфиги и парная оценка на одинаковых входах.
- **Работа с реальными видео.** Поворот, переменная частота кадров, кириллица
  и пробелы в путях; декодирование и рендеринг через PyAV.
- **Необязательная автоматическая инициализация.** SAM3 может подготовить
  первую маску документа для последующего инференса Cutie.

## Быстрый старт

### Установка

Понадобятся Git, [uv](https://docs.astral.sh/uv/getting-started/installation/)
и Python 3.12. Основная конфигурация использует NVIDIA GPU, PyTorch 2.14.1
и CUDA 13.0. Зависимости и их версии устанавливаются из `uv.lock` в `.venv`.
Системные `ffmpeg` и `ffprobe` для работы приложения не требуются.

```bash
git clone https://github.com/Misha-m-st/misis2026f-24-cv-4-makarov-m-a.git document-vos
cd document-vos
uv sync --locked
```

Основная платформа — Linux. Для Windows предусмотрен запуск в Ubuntu через
WSL2; отдельная проверка WSL2 пока не выполнена. Подробности окружения и
фактические проверки — в [отчёте о проверках](docs/VALIDATION.md).

### Первый результат на готовом примере

> **Статус Release:** веса и 12 небольших примеров подготовлены локально,
> но Release ещё не опубликован. Сетевые URL в каталогах относятся к будущему
> Release; приведённая ниже цепочка скачивания станет доступна после публикации.
> Для локальных пакетов команды `setup` и `download --sample` принимают `--catalog`.

```bash
uv run document-vos setup
uv run document-vos download --sample
uv run document-vos infer --sample
```

`setup` получает закреплённый upstream Cutie и веса. Следующие две команды
скачивают небольшой готовый пример и обрабатывают его моделью `finetuned`.
По завершении CLI выводит прямые пути к MP4, папке результатов и HTML-индексу.

По умолчанию используется одна последовательность SmartDoc2015:
188 кадров, около 7,2 МБ в ZIP. Для этого сценария обучающие датасеты скачивать
не нужно. Посмотреть точный состав и объём можно без загрузки:

```bash
uv run document-vos download --sample --plan
```

Другой датасет и количество примеров выбираются явно. На каждый датасет
доступны две фиксированные валидационные последовательности:

```bash
uv run document-vos download --sample --dataset midv2020 --count 2
uv run document-vos infer --sample --dataset midv2020 --count 2
```

Примеры содержат исходные кадры и первую маску из разметки датасета.
Они позволяют проверить весь процесс инференса и относятся к валидации.

## Свои видео

Положите видео в `data/videos/` и добавьте рядом начальную маску либо файл
с четырьмя углами документа:

```text
data/videos/
├── example.mp4
└── example.mask.png       # либо example.corners.json
```

PNG должна быть одноканальной, совпадать с размером первого ориентированного
кадра и содержать значения 0/1 или 0/255. Формат углов — четыре точки по обходу:

```json
[[100, 100], [900, 100], [900, 650], [100, 650]]
```

Координаты относятся к первому кадру после применения поворота видео.
Если рядом лежат и PNG, и JSON, подготовка сообщит о неоднозначности.

```bash
uv run document-vos infer
```

Команда автоматически подготовит кадры и первую маску. Можно указать другую
папку или выбрать исходную модель:

```bash
uv run document-vos infer --input-dir "мои видео"
uv run document-vos infer --model baseline
```

Явная подготовка доступна через `prepare videos`. Её результат содержит
`review_initial/`: удаление превью исключает соответствующее видео из
последующей обработки. Повторная подготовка с теми же входами не восстанавливает
удалённое превью. Готовая папка передаётся через `infer --input-dir`.

Для автоматического получения первой маски доступен [необязательный SAM3](docs/SAM.md):

```bash
uv run document-vos setup --sam
uv run --extra sam document-vos prepare videos --sam
```

Обычный инференс Cutie работает без SAM3. Его автоматические маски считаются
псевдоразметкой; подробности выбора маски и проверки геометрии описаны в
[документации SAM3](docs/SAM.md).

## Модели и результаты

| Модель | Назначение | Веса |
|---|---|---|
| `baseline` | Исходная Cutie base-mega | `cutie-base-mega.pth` |
| `finetuned` | Cutie, дообученная на видео документов; выбор по умолчанию | `cutie-document.pth` |

Сохранённая парная оценка охватывает **717 валидационных видео** из шести
датасетов и **37 884 кадра** после инициализации. Обе модели используют
одинаковые кадры, первые маски и настройки. Внутренний размер инференса — 480;
PNG-маски и оценка сохраняют исходное разрешение.

| Метрика, % ↑ | baseline | finetuned |
|---|---:|---:|
| J — IoU маски | 98,07 | **99,15** |
| DAVIS F | 97,69 | **99,75** |
| J&F | 97,88 | **99,45** |
| Boundary IoU | 90,25 | **94,92** |

Усреднение даёт одинаковый вес датасетам, а внутри каждого датасета — видео.
Источник результатов, протокол и проверка происхождения приведены в
[отчёте об эксперименте](docs/REPORT.md); назначение и ограничения модели —
в [карточке модели](docs/MODEL_CARD.md).

Эти числа характеризуют качество масок на фиксированной валидации.
Метрики углов и сторон страницы отдельно не измерялись: рост J&F и Boundary IoU
сам по себе не доказывает точность геометрического выравнивания документа.

## Обучение и воспроизведение

Обучение начинается с `baseline`. Подготовка нормализует датасеты, строит
маски из углов, создаёт разбиение и training-export:

```bash
uv run document-vos download --plan
uv run document-vos download
uv run document-vos prepare datasets
uv run document-vos train
```

Основной рецепт включает **2836 обучающих и 717 валидационных последовательностей**,
всего **200 106 кадров**. Исключена 21 последовательность DLC с пустой исходной
разметкой; причины и контрольные суммы сохранены. Разбиение учитывает связанные
документы и шаблоны, один объект обрабатывается без смешивания последовательностей.

| Параметр | Основной рецепт |
|---|---|
| Seed / итерации | 42 / 30 000 |
| Batch / длина последовательности | 2 / 8 кадров |
| Crop / reference frames | 480×480 / 3 |
| Learning rate / AMP | `1e-5` / включён |

Команда `reproduce` выполняет полный протокол: подготовку, обучение,
инференс обеих моделей, парную оценку и формирование отчёта:

```bash
uv run document-vos reproduce
```

Она использует локальные данные и зависимости, а при нехватке входов сообщает
необходимую команду скачивания. Изменение научных параметров допускается в
`train` и `infer`; для воспроизведения проверяется соответствие основному рецепту.
Продолжение завершённых этапов доступно через `reproduce --resume ПАПКА` после
проверки входов и артефактов. Прерванное обучение внутри этапа не продолжается.

Обучение на 30 000 итераций — длительная операция. Для короткой проверки
сохранения checkpoint и всего парного процесса предусмотрен CUDA smoke:

```bash
uv run document-vos tools smoke
```

Он выполняет две итерации на синтетических входах и проверяет исполнение.
Подробнее о данных, ресурсах и протоколе — в [руководстве по воспроизведению](docs/REPRODUCING.md).

## Настройка и результаты запусков

Все основные настройки собраны в [config.yaml](config.yaml): пути, датасеты,
модель, подготовка, обучение, инференс, визуализация и ресурсы исполнения.
Приоритет: **CLI → конфиг → встроенные значения**. Пути в YAML считаются
относительно файла конфига, пути CLI — относительно текущей папки.

```bash
uv run document-vos infer --config config.yaml --max-internal-size 480
uv run document-vos infer --weights weights/my-model.pth --output results/my-run
uv run document-vos infer --help
```

Новые артефакты распределяются по следующим папкам:

```text
data/
├── archives/       # полные архивы датасетов
├── raw/            # нормализованные исходные данные
├── samples/        # небольшие примеры для инференса
├── videos/         # собственные видео и первые маски
└── prepared/       # подготовленные кадры, манифесты, разбиения и training-export
weights/            # модели
.cache/             # upstream Cutie и служебные кеши
results/            # отдельная папка для каждого запуска и общий index.html
```

Запуск хранит конфиг, статус, сведения о происхождении, журналы, `summary.md`
и HTML-страницу со ссылками на видео. Подготовленные данные переиспользуются
после проверки входов и настроек. Папки результатов не перезаписываются.

## Разработка

Диагностики и операции с явными промежуточными входами доступны в группе `tools`:

```bash
uv run document-vos tools --help
uv run --extra dev ruff check src tests
uv run --extra dev pytest -q
```

Проверки официального loader требуют `CUTIE_ROOT`; команды и условия запуска
приведены в [VALIDATION.md](docs/VALIDATION.md). Ошибки и предложения можно
обсуждать в [Issues](https://github.com/Misha-m-st/misis2026f-24-cv-4-makarov-m-a/issues),
указав команду запуска, версию окружения и журнал ошибки.
