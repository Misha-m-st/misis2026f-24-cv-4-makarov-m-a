# SAM3: необязательная первая маска

```bash
uv run document-vos setup --sam
uv run --extra sam document-vos prepare videos --sam
uv run document-vos infer --input-dir data/prepared/videos/ПАПКА
```

Setup получает локальные веса. При первом получении весов Facebook SAM3 может
потребоваться доступ в Hugging Face и принятие условий автора.
Код SAM3 закреплён commit 0570b3a5be9c4e694f23d85232fb55f4a6f1f7fc.
Обычные setup/train/infer не импортируют SAM3 и не требуют этого дополнения.

По умолчанию SAM3 размечает первый кадр. Расширенная настройка `sam.step: 10`
или `prepare videos --sam --step 10` включает разреженную сетку.
Используются выбор крупнейшей непересекающейся маски после confidence-порога и
проверки поддержки сторон четырёхугольника. Нет выбора победителя по confidence
и нет instance_margin. Ошибка первой маски исключает видео; ошибка последующей
разметки сохраняет видео и кадры для распространения маски Cutie.

Маски SAM3 и восстановленная геометрия — автоматические псевдометки без ручной
проверки, а не GT. Превью находятся в review_initial/. Удалённое пользователем
PNG исключает соответствующую последовательность; повторный запуск подготовки
не восстанавливает его. Для изменённых входов создаётся новая подготовка.
