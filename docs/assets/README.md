# Иллюстрации README

Обе иллюстрации относятся к одной валидационной последовательности:
`smartdoc2015/background05/patent004`. По сохранённой оценке исходной Cutie
это второй худший пример по J&F среди 25 SmartDoc-видео: 86,17% до дообучения
и 99,21% после. Пример выбран для демонстрации ошибки границы;
общие результаты приведены в [отчёте](../../experiment_report.pdf).

## Анимация

`document-tracking.gif` содержит все 80 кадров в исходном порядке.
Слева — `Base Cutie`, справа — `fine-tuned Cutie`. Обе панели используют
один исходный кадр и соответствующие ему сохранённые предсказания,
включая общую GT-маску инициализации на первом кадре.

Локальные источники относительно корня репозитория:

- Кадры: `data/raw/smartdoc2015/background05/patent004/frame_0001.jpeg` — `frame_0080.jpeg`.
- Исходная модель: `results/retraining-v2-attempt2/new-validation/baseline/`.
- Дообученная модель: `results/retraining-v2-attempt2/new-validation/v2/`.
- В каждой папке модели `selected-manifest.jsonl` задаёт исходные кадры,
  а `predictions.jsonl` связывает их с PNG-масками и SHA-256.
- Ранг примера и метрики: `baseline-eval/videos.csv` и `v2-eval/videos.csv`
  в той же папке `new-validation/`.

Перед сборкой проверены совпадение манифестов, соответствие всех 80 кадров
обеим моделям и SHA-256 всех 160 масок. Повторный инференс не выполнялся.
Полупрозрачная зелёная заливка имеет alpha 0,27; контур строится из маски.
Панели одинаково уменьшены до 512×288, итоговый размер — 1024×288,
общая палитра — 128 цветов. Надписи белые с тёмной обводкой для читаемости.
Внизу слева указано только название датасета.

Частота — 10 кадров/с, длительность цикла — 8 секунд. В манифесте
`time_source=unknown`, поэтому это скорость просмотра, а не исходная
частота съёмки. Порядок кадров и синхронизация панелей сохранены.

## Увеличенный кадр

`document-boundary-crop.png` — исходный PNG рисунка 1 из
`experiment_report.odt`, соответствующий рисунку 1 на странице 3
[PDF-отчёта](../../experiment_report.pdf). Изображение извлечено без изменений:
вверху показан документ с отмеченной областью, внизу — её увеличение.
Это кадр 12 той же последовательности. Boundary IoU на нём:
77,24% у исходной и 94,99% у дообученной модели.

## Источник и лицензия

Исходные кадры: Burie et al., ICDAR 2015,
[SmartDoc2015](https://github.com/jchazalon/smartdoc15-ch1-dataset),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
В анимацию добавлены предсказанные маски и подписи, кадры уменьшены;
статическая иллюстрация содержит обрезанные и увеличенные фрагменты.
