# Замер вместимости обучения

Из корня проекта, после экспорта train и установки CUDA PyTorch:

```bash
uv run document-vos tools capacity \
  --weights weights/cutie-base-mega.pth \
  --export data/prepared/training-export \
  --output data/benchmarks/training-capacity-new \
  --workers 4
```

Скрипт начинает с официального main_training: batch 16, 8 кадров,
crop 480×480, 3 reference frames, AMP. Для задачи документов сохраняются
обязательные отличия: только main_training, один объект, без слияния видео,
локальные исходные веса и только экспортированный train.
Loss, AdamW, scheduler, аугментации и forward/backward берутся из зафиксированной
официальной Cutie; её исходники не изменяются.

Только CUDA OOM разрешает следующий вариант: batch 8 → 4 → 2 → 1,
затем 5 кадров, 3 кадра и наконец crop 384. На первом PASS выполнение заканчивается.
Ошибка данных, CPU memory, nonfinite loss или аварийный выход не разрешают
автоматическое снижение. Каждый вариант запускается в новом torchrun-процессе.

По умолчанию 5 прогревочных и 5 измеряемых шагов. Проверяются finite loss
и реальные optimizer updates во всех измеряемых шагах (AMP может пропустить
шаг при переполнении градиентов). CUDA синхронизируется до/после шага.
Время Trainer включает transfer, forward, loss, backward и optimizer;
полное время дополнительно включает ожидание следующего batch.
CPU prefetch ограничен одним batch на worker, чтобы не расходовать лишнюю RAM.

Сохраняются `resolved.yaml`, `runtime.json`, `run.log` каждого варианта,
официальная исходная конфигурация и общий `summary.json`: loss, AMP scale,
optimizer updates, времена, peak allocated/reserved VRAM, GPU, версии и хеши
весов/экспорта/манифеста. Модель и optimizer checkpoints не сохраняются.

Это короткая проверка вместимости на реальных случайно выбранных обучающих
последовательностях, а не оценка качества или гарантия полного длительного запуска.
Полная повторная проверка всех файлов экспорта не выполняется: проверяется
происхождение train/split, а выбранные примеры читает официальный dataset.
Веса исходной модели остаются неизменными. Профиль инференса этим замером
не выбирается; crop обучения отличается от resize полного кадра при инференсе.
